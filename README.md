# JF Eventos — Landing Page

Landing page do **JF Eventos**, espaço para casamentos, aniversários, chá de revelação e eventos corporativos em Guareí-SP.

📍 Av. Ataliba Figueira, nº 122 – Centro, Guareí-SP · CEP 18.250-075
📱 WhatsApp: (15) 99761-5353 · Instagram: [@_eventosjf](https://www.instagram.com/_eventosjf)

## Tecnologias
- HTML5, CSS3 e JavaScript puro (sem build)
- [GSAP](https://gsap.com/) + ScrollTrigger: animações de entrada, scroll horizontal fixado, parallax, textos revelados
- [Lenis](https://lenis.darkroom.engineering/): rolagem suave
- Canvas: partículas douradas no topo e chuva de confete na chamada final

## Rodar localmente
Basta abrir o `index.html` no navegador.

## Trocar as fotos
Coloque as fotos reais na pasta [`img/`](img/) com os nomes listados em [`img/LEIA-ME.txt`](img/LEIA-ME.txt) (ex.: `capa.jpg`, `salao-1.jpg`, `galeria-1.jpg`).
Cada foto com o nome certo substitui automaticamente a imagem ilustrativa; as que faltarem continuam com a foto de exemplo do Unsplash.
